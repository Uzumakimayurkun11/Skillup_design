# SkillUp — Small steps. Real growth.

SkillUp is a learning app concept that makes building new skills feel clear and achievable. Explore its onboarding journey, course discovery, lessons, progress, and profile screens in a responsive, clickable preview.

**[Open the live demo](https://uzumakimayurkun11.github.io/Skillup_design/)** · [View the repository](https://github.com/Uzumakimayurkun11/Skillup_design)

## Highlights

- Interactive browser for all 32 designed screens
- Search, screen navigation, and full-size previews
- Learning goals, reminders, subscriptions, course paths, lessons, and progress
- Responsive layout with SkillUp’s cream, lime, coral, and charcoal colors

## Built with

HTML, CSS, and JavaScript, with original screen exports from Figma.
